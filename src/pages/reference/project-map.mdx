# Project map :badge[Partial]{warning}

This map connects public docs concepts to the source that implements the current triad runtime.

## Machine, wallet, and VFS

| Concept | Source |
| --- | --- |
| CLI, Machine lifecycle, and IPC clients | `crates/bloom/src/` |
| Machine binary | `crates/bloom-machine/src/` |
| Machine-to-Broker protocol client and projection cache | `crates/bloom-machine-client/src/` |
| Key-free daemon wiring and execution adapters | `crates/bloom-daemon/src/` |
| Virtual filesystem router and handlers | `crates/bloom-vfs/src/` |
| Vendored in-filesystem docs | `crates/bloom-vfs/src/docs/` |
| Unsigned transaction staging, simulation, signing orchestration, broadcast, and nonce management | `crates/bloom-tx/src/` |
| EVM chain engines and RPC pools | `crates/bloom-evm/src/`, `crates/bloom-rpc/src/` |
| Paid HTTP, x402, and MPP | `crates/bloom-paid-http/src/`, `crates/bloom-paid-x402/src/`, `crates/bloom-paid-mpp/src/` |
| Watch subscriptions and polling executor | `crates/bloom-watch/src/` |
| NFS mount adapter | `crates/bloom-mount/src/` |
| ENS, Etherscan metadata, and prices | `crates/bloom-ens/src/`, `crates/bloom-etherscan/src/`, `crates/bloom-prices/src/` |
| Hashing, ABI, RLP, units, and EIP-712 helpers | `crates/bloom-tools/src/` |
| Shared config, audit, intent, policy, plan, path, and protocol types | `crates/bloom-proto/src/` |

There is no Machine-local `bloom-keystore` or `bloom-auth` authority crate in the production graph.

## Authority services

| Responsibility | Repository |
| --- | --- |
| Policy, exact reviews, Sealed Approvals, ceremony HTTP, authorization, and Machine-facing authority RPC | [`bloom-directory/bloom-broker`](https://github.com/bloom-directory/bloom-broker) |
| Wallet/delegated keys, credentials, canonical policy custody, replay/counter enforcement, and signatures | [`bloom-directory/bloom-signer`](https://github.com/bloom-directory/bloom-signer) |
| Versioned RPC wire, authenticated local transport, activation, trusted time, and audit-checkpoint substrate | [`bloom-directory/bloom-service-runtime`](https://github.com/bloom-directory/bloom-service-runtime) |

Machine never connects directly to Signer.

## Petal packages and runtime

| Concept | Source |
| --- | --- |
| Installed package validation, route execution, host capabilities, and payload-bearing signing bridge | `crates/bloom-petals/src/` |
| Petal ABI and host interfaces | `crates/bloom-petals/src/abi.rs`, `crates/bloom-petals/src/host.rs` |
| Package/provenance handling | `crates/bloom-petals/src/package.rs`, `crates/bloom-petals/src/store.rs` |
| WASM runtime | `crates/bloom-petals/src/vm.rs` |
| Default package release/build tooling | [`bloom-directory/petal`](https://github.com/bloom-directory/petal) and each Petal repository |

Venue-specific applications such as Enso, Polymarket, and Hyperliquid live in installed Petal packages rather than native Machine authority paths.
